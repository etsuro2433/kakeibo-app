# 設楽香織さん 英語レッスン用スプレッドシート

## 前提条件
- **ゴール**: 9月ニューヨーク渡航までに日常会話（準2級レベル：話す・聞く）を習得
- **再スタート期間**: 2026年5月17日〜6月30日（私の担当レッスン期間）
- **7月〜出国まで**: ネイティブレッスン 1h/日（別枠）
- **1日の学習時間**: 朝1h ＋ 夜2h（多い日は夜3h） ＋ 移動中リスニング
- **単語**: 1日3回確認、1日10単語×7日 = 70問 / 週1回テスト・90%クリア目標
- **学習スタイル**: 会話ベース（話す・聞く中心、ライティングは会話関連分のみ）
- **現状レベル**: 英検3級程度（昨年NY数ヶ月滞在経験あり）
  - → 定型文・瞬間英作文は**シンプルすぎない**準2級寄りの内容で構成

| 7 | リクエスト | `07_request.csv` | 香織さんからの質問・要望 |

## Googleスプレッドシートへの取り込み手順
1. Googleスプレッドシートで新規ファイル作成（ファイル名例: `設楽香織_英語レッスン_2026-05〜06`）
2. 各CSVについて：`ファイル → インポート → アップロード` で1ファイルずつアップロード
3. インポート場所で **「新しいシートを挿入」** を選択
4. シート名（タブ名）を上記の日本語名にリネーム
5. 共有設定で香織さん・私を編集権限で追加

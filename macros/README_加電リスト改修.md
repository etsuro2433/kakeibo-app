# 加電リスト 改修 — 導入・操作ガイド

`output/企業リスト_作業中.xlsx` を以下のように改修しました。
このドキュメントは **(A) 今すぐ使える内容**(マクロ不要)と
**(B) .xlsmに変換してフル機能化**(VBA導入)の2段構えで書いています。

---

| 項目 | 内容 |

## (A) まず .xlsx のままで使える機能

`.xlsm` への変換は後でも構いません。まずはこれだけで多くが解決します。

### A-1. 連動プルダウン(エリア → 企業名)

`加電履歴` シートを開いて、次の順番で入力するだけです。

1. **E列「種別」** … `JA / 畜種農業` から選択(空欄でも可)
2. **F列「エリア」** … `道央 / 道北 / 道東 / 道南` から選択
3. **G列「企業名」** … 上で選んだエリアの企業だけがプルダウンに出ます

> 種別を空欄にすると、そのエリアの **JA+畜種の全企業** がプルダウンに出ます。

### A-2. 知っておくと便利な Windows Excel ショートカット

| キー | 動作 |
|---|---|
| `Ctrl + ;` | セルに **今日の日付** を入力 |
| `Ctrl + :` (= `Ctrl + Shift + ;`) | セルに **現在時刻** を入力 |
| `Alt + ↓` | アクティブセルのプルダウンを開く |
| `Tab` | 次の入力欄へ移動 |
| `Enter` | 確定して下のセルへ |
| `Ctrl + .` | 入力中の選択範囲内で次のセルへ |

> 日付ショートカットは「とにかく速い」ので、カレンダーピッカーよりこれを覚えるのが実務的にはおすすめです。

### A-3. シートを「行ったり来たり」しない技

#### 方法1: ウィンドウを2枚開いて並べる(マクロ不要・推奨)

1. 上部メニュー **`表示`** → **`新しいウィンドウを開く`**
2. もう一度 **`表示`** → **`整列`** → `左右に並べて表示` を選択 → OK
3. 左ウィンドウで「JAリスト」、右ウィンドウで「加電履歴」を開く
4. これで **どちらも同時に見える** ようになります。1つのファイルなので保存も同期します

> 1台のモニタでも可ですが、デュアルモニタなら片方を別画面にドラッグすると最強です。

#### 方法2: 📝加電入力 シート(後述のVBA併用が前提)

「種別/エリア/企業名/結果」をプルダウンから選ぶだけのフォーム画面です。
**登録ボタン** を押すと `加電履歴` に自動転記され、元リストの「加電回数」も同時に増えます。

## (B) フル機能化 — .xlsm に変換して VBA を導入

### 🚀 推奨: 自動セットアップ (1クリック)

PCの操作はこれだけです。**約30秒で .xlsm が完成します。**

1. リポジトリ全体を ZIP でダウンロード
   - https://github.com/etsuro2433/kakeibo-app/archive/refs/heads/claude/verify-company-data-QSOs7.zip
2. ZIPを展開(右クリック → すべて展開)
3. 展開したフォルダの中の **`setup/セットアップ.bat`** を **ダブルクリック**
4. 黒い画面が出るのでEnterキー → 自動的にExcelが起動して組み立てが進む
5. 「完了しました」と出たら `output/企業リスト_作業中.xlsm` が出来上がっています

このスクリプトは:
- Excel COM 経由で .xlsx を開いて
- modKaden / modDatePicker / ThisWorkbook の VBA コードを取り込み
- 「📝 加電を登録」「✓ 登録」「↺ クリア」ボタンを各シートに配置
- 「VBAプロジェクトへのアクセス」設定を一時的にONにして、終了時に元に戻す
- .xlsm として保存

を全部自動でやります。

> ⚠ Excelがインストールされていない / Excel for Mac の場合はこの自動セットアップは
> 使えないため、下記の「手動セットアップ」を参照してください。

---

### 🔧 手動セットアップ (Excelが無い/うまく動かない場合)

ダブルクリックでカレンダーを出す/登録ボタンを使う場合は、こちらの作業が必要です。

### B-1. .xlsm として保存

1. `output/企業リスト_作業中.xlsx` を Excel で開く
2. `ファイル` → `名前を付けて保存`
3. ファイルの種類: **`Excel マクロ有効ブック (*.xlsm)`** を選択 → 保存
4. 以降は `企業リスト_作業中.xlsm` を使用

### B-2. VBA エディタを開いてモジュールをインポート

1. Excel で `Alt + F11` を押す(VBA エディタが開く)
2. 左ペインの **`VBAProject (企業リスト_作業中.xlsm)`** を右クリック
3. `ファイル` → `ファイルのインポート` で以下の3ファイルを順に取り込む
   - `macros/modKaden.bas`
   - `macros/modDatePicker.bas`
4. **ThisWorkbook** にイベントコードを貼り付け:
   - 左ペインで `Microsoft Excel Objects` → `ThisWorkbook` をダブルクリック
   - **既存の中身を全選択して削除**
   - `macros/ThisWorkbook.cls` の中身をすべて貼り付け
     (※`.cls` ファイルの先頭の `VERSION` ヘッダー行〜属性行はインポート時のみ必要。
       コピペで貼る場合は **`Option Explicit` の行から下** を貼り付けてください)
5. Excel に戻って **`Ctrl + S`** で保存(マクロ有効ブックなのでこれで永続化)

### B-3. ボタンを各シートに配置

各シートの上部に **「📝 加電を登録」ボタン** を1個ずつ追加します。

1. リボン `挿入` → `図形` → 角丸四角形を1つ描画 (お好みのサイズで)
2. 図形を右クリック → **`マクロの登録`**
3. マクロ名 **`OpenKadenForm`** を選択 → OK
4. 図形のテキストを **`📝 加電を登録`** に変更
5. **JAリスト / 畜種農業 / 加電履歴** の3シートにこのボタンを配置(コピペでOK)

📝加電入力シートには **2つのボタン** を:

| 図形テキスト | 登録するマクロ |
|---|---|
| `✓ 登録` | `RegisterKaden` |
| `↺ クリア` | `ClearKadenForm` |

### B-4. 使い方フロー

#### 通常の加電登録
1. JAリスト(または畜種農業)を見て今から電話する企業を確認
2. 上部の **`📝 加電を登録`** をクリック
3. 📝加電入力 が開き、日付セルに今日が入る
4. `Ctrl + :` で現在時刻入力 → 種別 → エリア → 企業名 をプルダウンで選択
5. 結果・メモ・次回ToDoを入れて **`✓ 登録`**
6. **加電履歴** に1行追加 + **元シートの加電回数が +1** され、最終加電日・最終結果も更新

#### 日付セルをダブルクリックでカレンダー
- `加電履歴` の **B列(日付)** / **M列(次回予定日)** をダブルクリック → カレンダーが表示
- `◀` `▶` で月移動、日付をクリックで確定
- 他シートをクリックするとキャンセル

## ⚙️ トラブルシューティング

| 症状 | 対処 |
|---|---|
| プルダウンに何も出ない | エリアを先に選んでいるか確認。`_master` シートが残っているか確認(削除しないこと) |
| `INDIRECT` で `#REF!` | 名前付き範囲 `道央/道北/道東/道南/JA_道央/CH_道央 …` が存在するか、`数式 → 名前の管理` で確認 |
| マクロが動かない | `ファイル → オプション → セキュリティセンター → マクロの設定` で「警告を表示してすべてのマクロを無効にする」に設定し、ファイルを開く時にバーから「コンテンツの有効化」を押す |
| ダブルクリックしてもカレンダーが出ない | `ThisWorkbook` モジュールに `Workbook_SheetBeforeDoubleClick` がきちんと貼られているか確認 |
| カレンダーが消えない | `_picker` シートを右クリック → 非表示で隠す。または `g_PickerSelected = "CANCEL"` をイミディエイトウィンドウで実行 |

## 💡 補足: 真のカレンダーコントロール(MonthView)について

Microsoft Date and Time Picker / Calendar Control は **64-bit 版 Excel では使えません**。
本実装は外部コントロールに依存しない自作カレンダーなので、32/64bit 両対応です。
ただし「セルにくっついたドロップダウンカレンダー」のような UI ではなく、
シート上にカレンダーが現れるタイプです。実用上は問題ありません。
